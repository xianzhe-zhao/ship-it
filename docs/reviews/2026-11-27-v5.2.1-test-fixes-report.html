4. C3 run_suite 返回码语义

问题
测试有 7 FAIL + 4 ERROR，但 run_suite.py 返回 2（SKIP），CI 当通过
改了什么

有 FAIL/ERROR 就返回 1，只有纯 SKIP（无 FAIL/ERROR）才返回 2

为什么改

FAIL 优先级高于 SKIP，避免 CI 假绿

逻辑流程图
graph TD
    A[测试运行完成] --> B{有 FAIL 或 ERROR?}
    B -->|是| C[返回 1]
    B -->|否| D{有 SKIP?}
    D -->|是| E[返回 2]
    D -->|否| F[返回 0]
    C --> G[CI 报错]
    E --> H[CI 通过但标记 SKIP]
    F --> I[CI 通过]
代码对比
- if report["skipped"]: - return 2 - return 0 if report["ok"] else 1 + if report["failures"] > 0 or report["errors"] > 0: + return 1 + if report["skipped"] > 0: + return 2 + return 0
改动位置
  • tests/run_suite.py 第 250–252 行
怎么验证

运行 python -m tests.run_suite，有 FAIL 时返回 1，纯 SKIP 时返回 2

5. C4 local_check 编码兜底

问题
中文 Windows 下 UnicodeDecodeError → TypeError: can only concatenate str (not "NoneType") to str
改了什么

加 errors="replace" 参数

为什么改

解码失败时用 替代，不崩溃

代码对比
- proc = subprocess.run(cmd, capture_output=True, text=True, encoding="utf-8", cwd=str(root)) + proc = subprocess.run(cmd, capture_output=True, text=True, encoding="utf-8", errors="replace", cwd=str(root))
改动位置
  • ship-it/scripts/local_check.py 第 65 行
怎么验证

在中文 Windows 下运行 python ship-it/scripts/local_check.py，不崩溃

7. C6 测试残留清理

问题
