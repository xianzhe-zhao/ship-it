## 2. 在其他环境拉取与解压

```bash
git fetch origin test/v4.7.1-snapshot
git checkout test/v4.7.1-snapshot
# 解压所有 .gz（覆盖同名旧源码）
find . -name '*.gz' -not -path './.git/*' -exec gunzip -f {} \;
# 检查版本
grep '^version:' ship-it/SKILL.md   # 应为 4.7.1
# 提交解压结果
git add -A
git commit -m "chore: unpack v4.7.1 snapshot"
```

## 3. 合并到 main

```bash
git checkout main
git merge --ff-only test/v4.7.1-snapshot
git push origin main
```

- 分支含旧源码 + `.gz`；解压会覆盖旧源码，必须检查 `ship-it/SKILL.md` 为 4.7.1。
- 合并后跑：`check_text`、`check_docs`、`check_spec --stage spec/verify`、`check_roles --stage start/verify`。
- **主脑不合并、不推送 main；合并与推送由用户本人执行。**
