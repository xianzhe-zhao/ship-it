# 角色名词典（权威）

> 本文件是 ship-it 团队模式角色名的唯一权威来源，check_terms.py 读取本校验。
> 改角色名必须先改本词典，再改正文；历史 CHANGELOG/历史 spec 中的旧名走 allowlist 保留。

## 权威角色名

| 角色名 | 别名（历史） | 一句话定义 |
|---|---|---|
| 主脑 | - | 项目负责人与技术总指挥，9 步契约流程唯一 owner，唯一对用户交付的成员 |
| 需求分析师 | 需求澄清员 | 需求分析师，把模糊需求澄清成可签约的优化需求 |
| 后端开发 | - | 后端工程师，负责接口/数据/逻辑层 |
| 前端开发 | - | 前端工程师，负责页面/组件/样式层 |
| 代码安全员 | 代码审查员 | 代码审查与安全工程师，代码正确性+安全双把关 |
| 监察员 | 审查员 | 过程监察与调度督导，主脑唯一汇总接口与 watchdog |
| 测试员 | - | 验收测试工程师，拥有测试执行权 |
| 裁判员 | - | 契约合规审计师，规则符合性审计 |

## allowlist（历史文件旧名允许保留）

以下文件中的旧角色名（审查员/需求澄清员/代码审查员）允许保留，check_terms.py 不判 FAIL：

- ship-it/CHANGELOG.md（历史版本记录）
- CHANGELOG.md（根，历史版本记录）
- docs/specs/*.md（历史 spec，历史真相档案）

## 改名纪律

- 改角色名必须先改本词典的角色名列和别名（历史）列。
- 旧名移入别名（历史）列，并加入上方 allowlist 文件清单（如果是历史保留）。
- 正文范围（SKILL.md / team-mode.md / spec-template.md / README.md / deploy-runbook.md）必须使用权威名，不得用旧名。
