### check_docs.py resolve_spec 改造（核心技术点）

当前逻辑（236-270 行）：
```
if spec_arg: 用指定
elif DEFAULT_SPEC(硬编码11-19).exists(): 用它   # ← bug：优先用旧硬编码
else: 扫 docs/specs/*.md 取 sorted[-1]            # 本应是默认路径
```

改造后逻辑：
```
if spec_arg: 用指定（不变）
else:
    扫 docs/specs/*.md
    解析每个文件名中的版本号 v\d+.\d+.\d+（SemVer）
    取版本号最高的；并列最高取文件名日期最新
    无版本号的 spec 不参与版本号比较
    全部无版本号或无 spec → 降级取文件名日期最新（同一天取 mtime 最新）+ warning
```

需新增辅助函数 parse_spec_version_from_name(name) 解析文件名中的 v\d+.\d+.\d+。废除 DEFAULT_SPEC 硬编码。

## 7. 边界与异常

| 场景 | 期望表现 |
|---|---|
| docs/specs 下 spec 文件名无版本号 | 降级取文件名日期最新（同一天取 mtime 最新）+ warning，不崩溃 |
| docs/specs 为空 | warning "无 spec"，跳过条款计数检查，不崩溃 |
| 多个 spec 文件名版本号相同 | 取文件名日期最新者 |

## 8. 三问完整性检查 + DoR（不过不得开工）

- [x] ① **取值范围**：版本号为 SemVer 字符串（MAJOR.MINOR.PATCH，正则 ^\d+\.\d+\.\d+$）；spec_revision 为正整数；行数为非负整数 ≤350
- [x] ② **状态流转**：spec status ∈ {draft, signed, paused, accepted}，签约=draft→signed（用户"签约"），变更=signed→paused→draft（重签），验收=signed→accepted（用户"验收"）；check_docs 选 spec 无状态，纯函数选取
- [x] ③ **生成逻辑**：check_docs 默认 spec = max(docs/specs/*.md, key=(文件名版本号, 文件名日期))；SKILL.md 行数 = len(content.splitlines())
